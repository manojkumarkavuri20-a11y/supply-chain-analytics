## [1.0.0] - 2026-08-01

### Added
- Initial release of supply chain analytics SQL system
- `sql/lead_time_analysis.sql` — lead time analysis by supplier
- `sql/supplier_performance.sql` — supplier performance ranking and KPI scoring
- `sql/demand_forecasting.sql` — demand forecasting using moving averages
- `sql/stockout_risk.sql` — stockout risk flagging for at-risk products
- `data/` directory with synthetic sample dataset (CSV)
- `BLUEPRINT.md` — full project design and methodology notes
- README with project overview, schema details, and usage instructions
